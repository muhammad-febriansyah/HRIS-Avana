# AvanaHR Feature Assets

20 PNG assets hasil pemisahan dari feature asset sheet.

## Rekomendasi penggunaan
- Grid / mega menu: gunakan file PNG per fitur.
- `object-fit: contain`
- Lebar ideal di web: 180-320px per card.
- Untuk retina/high-DPI, file sudah di-upscale 3x.
